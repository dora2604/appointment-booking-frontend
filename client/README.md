# Appointment Booking Client (Angular + Tailwind)

## Run Locally
```bash
npm install
npm start
```

App URL: `http://localhost:4200`

## Key Frontend Features
- Standalone Angular components
- Angular routing + guards (`authGuard`, `roleGuard`)
- Reactive forms with validation
- HTTP client integration with JWT interceptor
- RxJS service-based state handling
- Tailwind responsive interface
- Loading and error states
